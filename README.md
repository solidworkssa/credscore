# CredScore

Decentralized credit scoring oracle adapter.

## Features
- Multi-chain support (Base & Stacks)
- Secure Contract Logic
- React/Next.js Frontend

## Contracts
- Base: `contracts/base/src/CredScore.sol`
- Stacks: `contracts/stacks/contracts/credscore.clar`

## Setup
```bash
pnpm install
pnpm dev
```
